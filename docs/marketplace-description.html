WAAAGH — Feign / Controller navigation for Spring Cloud projects.

WAAAGH is an IntelliJ IDEA plugin collection; popular tools may later be split into standalone plugins. This tool connects Spring Cloud @FeignClient interfaces with the @RestController / @Controller endpoints they map to, right inside the editor.

Features
  • Bidirectional navigation — matching methods show a gutter icon; click it to jump between a Feign method and its Controller endpoint.
  • Go to Declaration / Implementation — Ctrl+B / Ctrl+Click and Ctrl+Alt+B work between Feign clients and Controllers.
  • Call Hierarchy — on a Feign method, Callees list the Controller methods it maps to; on a Controller method, Callers list the Feign methods that reach it.
  • Copy URL — click the clipboard gutter icon to copy the complete request URL (context path + servlet path + package prefix + class path + method path).
  • Accurate matching — matched by full path + HTTP method; understands endpoints inherited from base API interfaces, duplicate mappings, many-to-many relations, and paths written as constants.
How to use
  1. Open a project with Spring Cloud OpenFeign clients and Spring MVC Controllers.
  2. Open a @FeignClient interface or a Controller class — matching methods get a gutter icon; click it to jump to the other side.
  3. Or put the caret on a method and press Ctrl+B (Go to Declaration) or Ctrl+Alt+B (Go to Implementation).
  4. Or press Ctrl+Alt+H (Call Hierarchy) to explore the mapping in both directions.
  5. Editor-tab icons for Feign / Controller classes can be toggled in Settings → search "WAAAGH".


中文

WAAAGH —— Spring Cloud 项目的 Feign ↔ Controller 跳转工具。

WAAAGH 是一个 IntelliJ IDEA 插件集合，受欢迎的工具未来可能会拆分成独立插件。 当前工具把 Spring Cloud 的 @FeignClient 接口与它们映射到的 @RestController / @Controller 端点连起来，直接在编辑器里跳转。

功能
  • 双向跳转 —— 匹配的方法旁会出现侧边栏图标，点击即在 Feign 方法与 Controller 端点之间跳转。
  • Go to Declaration / Implementation —— 在 Feign 与 Controller 之间使用 Ctrl+B / Ctrl+单击、Ctrl+Alt+B。
  • Call Hierarchy —— 在 Feign 方法上看 Callees，列出它映射到的 Controller 方法； 在 Controller 方法上看 Callers，列出会调用到它的 Feign 方法。
  • 复制 URL —— 点击侧边栏的剪贴板图标，复制完整请求 URL （上下文路径 + servlet 路径 + 包前缀 + 类路径 + 方法路径）。
  • 精确匹配 —— 按「完整路径 + HTTP 方法」匹配；支持从基础 API 接口继承的端点、 重复映射、多对多关系，以及写在常量里的路径。
怎么用
  1. 打开包含 Spring Cloud OpenFeign 客户端与 Spring MVC Controller 的项目。
  2. 打开 @FeignClient 接口或 Controller 类 —— 匹配的方法旁会出现侧边栏图标，点击即跳到对端。
  3. 或者把光标放在方法上，按 Ctrl+B（Go to Declaration）/ Ctrl+Alt+B（Go to Implementation）。
  4. 或者按 Ctrl+Alt+H（Call Hierarchy），双向查看映射关系。
  5. Feign / Controller 类的编辑器标签图标可在 Settings → 搜索 "WAAAGH" 中开关。
